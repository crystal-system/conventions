# Scopes

A scope of this repository targets one of the artifact kinds it
provides: the contributor documentation, the agent documentation,
or the CI workflows.

## docs

The contributor-facing documentation (CONTRIBUTING.md) that defines
the organization-wide conventions.

## agents

The agent-facing documentation (AGENTS.md) and its guidance for
AI agents acting on behalf of users.

## ci

The reusable GitHub Actions workflows that enforce the conventions.
